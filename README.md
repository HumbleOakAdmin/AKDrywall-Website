# A&K Drywall website preview

Three GitHub Pages versions of the A&K Drywall site. They use the live company details and stay `noindex` so they do not compete with [akdrywall.ca](https://akdrywall.ca/). Quote forms confirm on the page and do not email the office.

## Versions

- [Lite](https://humbleoakadmin.github.io/AKDrywall-Website/) — tighter version of the current site
- [Option 1](https://humbleoakadmin.github.io/AKDrywall-Website/option-1.html) — modern midpoint, the wall in four stages
- [Option 2](https://humbleoakadmin.github.io/AKDrywall-Website/option-2.html) — high-end showroom

Hard-refresh if an older layout is still cached. The pages are for review only.

Older addresses (`about.html`, `services.html`, `projects.html`, `contact.html`, and the rest) redirect into Lite.

## Publish

GitHub Pages serves the `main` branch root at `https://humbleoakadmin.github.io/AKDrywall-Website/`.
